# Документация Geometric_lib
Библиотека предоставляет набор функций для вычисления площади и периметра базовых геометрических фигур: треугольника, квадрата, прямоугольника и круга.

------------------------------
## Круг
Файл: [circle.py](https://github.com/IrinaSemenov/geometric_lib/blob/new_features_558434/circle.py)
## Содержание

* area(r)
* perimeter(r)

## area(r)
Назначение: вычисляет площадь круга по его радиусу.
### Параметры

| Имя | Тип | Описание |
|---|---|---|
| r | float | Радиус окружности |

### Возвращаемое значение

| Тип | Описание |
|---|---|
| float | Площадь круга, равная math.pi * r * r |

### Пример вызова
```
import math
result = area(3)
print(result) # ~28.274333882308138
```
## perimeter(r)
Назначение: вычисляет длину окружности (периметр круга) по его радиусу.
### Параметры

| Имя | Тип | Описание |
|---|---|---|
| r | float | Радиус окружности |

### Возвращаемое значение

| Тип | Описание |
|---|---|
| float | Длина окружности, равная 2 * math.pi * r |

### Пример вызова
```
import math
result = perimeter(3)
print(result) # ~18.84955592153876
```
------------------------------
## Прямоугольник
Файл: [rectangle.py](https://github.com/IrinaSemenov/geometric_lib/blob/new_features_558434/rectangle.py)
## Содержание

* area(a, b)
* perimeter(a, b)

## area(a, b)
Назначение: вычисляет площадь прямоугольника по двум сторонам.
### Параметры

| Имя | Тип | Описание |
|---|---|---|
| a | float | Сторона прямоугольника |
| b | float | Сторона прямоугольника, отличная по длине от a |

### Возвращаемое значение

| Тип | Описание |
|---|---|
| float | Площадь прямоугольника, равная a * b |

### Пример вызова
```
result = area(4, 6)
print(result) # 24
```
## perimeter(a, b)
Назначение: вычисляет периметр прямоугольника по двум сторонам.
### Параметры

| Имя | Тип | Описание |
|---|---|---|
| a | float | Сторона прямоугольника |
| b | float | Сторона прямоугольника, отличная по длине от a |

### Возвращаемое значение

| Тип | Описание |
|---|---|
| float | Периметр прямоугольника, равный 2 * (a + b) |

### Пример вызова
```
result = perimeter(4, 6)
print(result) # 20
```

## Квадрат
Файл: [square.py](https://github.com/IrinaSemenov/geometric_lib/blob/new_features_558434/square.py)
## Содержание

* area(a)
* perimeter(a)

## area(a)
Назначение: вычисляет площадь квадрата по длине его стороны.
### Параметры

| Имя | Тип | Описание |
|---|---|---|
| a | float | Сторона квадрата |

### Возвращаемое значение

| Тип | Описание |
|---|---|
| float | Площадь квадрата, равная a**2 (или a * a) |

### Пример вызова
```
result = area(5)
print(result) # 25
```

## perimeter(a)
Назначение: вычисляет периметр квадрата по длине его стороны.
### Параметры

| Имя | Тип | Описание |
|---|---|---|
| a | float | Сторона квадрата |

### Возвращаемое значение

| Тип | Описание |
|---|---|
| float | Периметр квадрата, равный 4 * a |

### Пример вызова
```
result = perimeter(5)
print(result) # 20
```

## Треугольник
Файл: [triangle.py](https://github.com/IrinaSemenov/geometric_lib/blob/new_features_558434/triangle.py)
## Содержание

* area(a, h)
* perimeter(a, b, c)

## area(a, h)
Назначение: вычисляет площадь треугольника по стороне и проведенной к ней высоте.
### Параметры

| Имя | Тип | Описание |
|---|---|---|
| a | float | Сторона треугольника, к которой проведена высота |
| h | float | Высота треугольника, проведенная к стороне a |

### Возвращаемое значение

| Тип | Описание |
|---|---|
| float | Площадь треугольника, равная a * h / 2 |

### Пример вызова
```
result = area(5, 4)
print(result) # 10.0
```
## perimeter(a, b, c)
Назначение: вычисляет периметр треугольника по трём сторонам.
### Параметры

| Имя | Тип | Описание |
|---|---|---|
| a | float | Длина первой стороны треугольника |
| b | float | Длина второй стороны треугольника |
| c | float | Длина третьей стороны треугольника |

### Возвращаемое значение

| Тип | Описание |
|---|---|
| float | Периметр треугольника, равный a + b + c |

### Пример вызова
```
result = perimeter(3, 4, 5)
print(result) # 12
```
